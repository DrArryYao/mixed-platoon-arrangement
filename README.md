# Mixed platoon arrangement

Numerical model code for *When Vehicle Arrangement Matters for String Stability in Mixed Platoons*, by Yuliang Zhang, Yi Wang, Yi Ai and Zhihong Yao.

## Run

Use Python 3.12 or a compatible version:

```sh
cd reproducibility
python -m pip install -r requirements.txt
python run_all.py
```

The scripts generate numerical results locally. Numerical figures 2–6 are written to `manuscript/figs`; figure 1 is the static schematic in the paper and is not generated by the experiments. The manuscript appendix specifies the experimental settings, seeds, units and validation conventions.

This repository contains scientific code and running instructions. Raw result files, reviewer correspondence and manuscript submission documents are excluded. Citation metadata are supplied in `CITATION.cff`; no archival DOI or reuse license has been assigned.
